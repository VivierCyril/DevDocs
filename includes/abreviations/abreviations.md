*[SSG]: Static Site Generator, générateur de site statique
*[CI/CD]: Continuous Integration / Continuous Delivery
*[RBAC]: Role-Based Access Control
*[HTML]: Hyper Text Markup Language, Langage de base du web. Il structure les contenus
*[W3C]: World Wide Web Consortium
*[CSS]: Cascading Style Sheets, Langage de style utilisé pour personnaliser l’apparence d’une page HTML
*[DWWM]: Développeur web & web mobile
*[JS]: JavaScript, Langage incontournable pour rendre un site interactif
*[Git]: Outil de versioning. Il permet de suivre l’évolution d’un projet, travailler à plusieurs et éviter les conflits dans le code.
*[API]: Application Programming Interface, Interface qui permet à différentes applications de communiquer entre elles. Par exemple, une app météo utilise une API pour afficher la température en temps réel.
